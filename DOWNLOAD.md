**Прежний Unity24_projects.zip не соответствует полному запросу и не подходит для сдачи.** Его прежний генератор больше не используется в новой переделке.

## Частичная переделка

[Скачать Unity24_rebuild_partial.zip](deliverables/Unity24_rebuild_partial.zip): открыть файл в GitHub, нажать **Download raw file**.

Внутри — новые исходные проекты часов **01,02,07,08,09,11,22,23**: 49 сохранённых сцен, 28 C#-файлов, префабы и физические материалы, инструкции и полный аудит 130 практических блоков книги. Это не полный комплект24 и не EXE. Импорт/компиляция API/Play в Unity2018.1.0f1 не выполнялись. Выполнены структурные проверки, синтаксический анализ и повторное создание из независимой чистой папки.

Исходники доступны прямо в [rebuild](rebuild). Открытие без Hub: Unity → File → Open Project → нужный HourNN → двойной щелчок на сцене в Assets/Scenes. Общего CourseSetup больше нет.

## Что требуется для продолжения

Оригинальные материалы из книги: http://addons.eksmo.ru/it/Unity.zip. Из облачной среды запрос блокируется сетевым прокси; разрешение пока сохранено лишь в черновике. Нужны архив или папки по главам либо применение и публикация сетевых настроек для повторной загрузки. Подменять модели, текстуры и анимации книги цветными примитивами новый комплект не должен.

Точные сцены, параметры материалов, UV/normal/Humanoid mapping и проверки: [часы1–12](audit/hours01-12.md), [часы13–24](audit/hours13-24.md).
