# Unity 2018.1.0f1 — проекты по24 часам книги

[Скачать весь комплект одним ZIP](https://github.com/Shinshilow/uniytu/archive/refs/heads/book-course-2018.zip)

В комплекте24 отдельных архива Hour01.zip…Hour24.zip. Каждый содержит папку с Assets и ProjectSettings, оригинальные ассеты книги и инструкцию ОТКРЫТЬ.md. Архив Unity.zip с материалами издательства получен из вашего релиза book-files; старые упрощённые комплекты здесь не используются.

## Как открыть без Unity Hub

1. Распакуйте общий ZIP, затем нужный HourNN.zip.
2. Запустите обычный Unity 2018.1.0f1 → File → Open Project → выберите HourNN (папку с Assets и ProjectSettings).
3. Дождитесь импорта. Откроется основная сцена; её путь также записан в ОТКРЫТЬ.md. Если не открылась, найдите сцену в Project и откройте двойным щелчком.
4. Нажмите Play. Практикумы внутри главы доступны в Assets/Scenes и отдельном проекте Practice, если он есть.

## Что восстановлено и что ещё не проверено

Включены оригинальные материалы/normal maps, модели с UV, paintedTerrain, тайлы/палитры, RobotBoy, Ethan с Humanoid, звуки, анимации и игровые механики автора. Дополнены недостающие сцены и творческие задания. Исходные проекты издательства были2018.1.0b3/b4; рабочие копии подготовлены для2018.1.0f1.

Проверены структура24 папок, реальные ссылки материалов/normal maps, бинарные TerrainData через запись+чтение, синтаксис C# по веткам Windows и целостность всех ZIP. **UnityEditor в облаке не запускался: импорт, компиляцияAPI, Play и EXE не проверены. Это исходные проекты, а не24 готовыхEXE или подтверждённые работы для сдачи.**

Часы17/19 сохраняют недостающие упражнения редакторным дополнением при первом импорте; эта подготовка здесь ещё не исполнялась. Час15 требует реальных отзывов игроков,22—телефона/UnityRemote,23—реальной сборки и запуска. Час24 содержит HTML-разбор игры и проект для анализа; собственные наблюдения нужно добавить после запуска.

Собрать EXE на своём компьютере: Book → Build Windows x64. Нужен Windows Build Support версии2018.1.0f1. Результат Builds/HourNN — передавать всю папку с EXE, *_Data и DLL.
