# Переделка по книге — частичный результат, не комплект из 24 готовых работ

Прежние проекты из Unity24/ и архив Unity24_projects.zip не соответствуют полному запросу и не должны использоваться для сдачи. Этот каталог создаётся заново по предоставленной книге для **Unity 2018.1.0f1**.

## Что изменено

- Каждому практикуму соответствует отдельная сохранённая сцена; итоговое упражнение не заменяет остальные задания главы.
- Объекты и компоненты уже находятся в .unity, а не создаются общим Lesson.cs при Play.
- Нет зависимости простых часов от Timeline, Tilemap или скриптов других глав.
- Ассеты материалов, импорт normal map, настройки рига и текстур должны соответствовать книге. Где нужны отсутствующие исходники, это блокер, а не повод заменить модель капсулой или текстуру одноцветной картинкой.
- Первые два часа и главы о базовом C# не требуют дополнительных текстур: не добавляем вымышленные требования.

## Открытие без Hub

Unity → File → Open Project → папка нужного HourNN. После импорта двойным щелчком открыть нужный .unity в Assets/Scenes. Список практикумов и итоговая сцена указаны в ОТКРЫТЬ.md каждого проекта. Меню Course/Prepare больше не нужно: сцены уже записаны на диск.

## Что действительно проверено

Выполнены проверки YAML, взаимных связей GameObject/Component, fileID/GUID, сцен в Build Settings, части числовых параметров по книге и синтаксиса C#. Они ловят, например, потерянные ссылки и отсутствие сохранённых текстур. Это **не** компиляция Unity API, импорт, Play или запуск EXE. Эти проверки пока UNRUN; готовность к сдаче не подтверждена.

## Внешние исходники

Книга прямо указывает архив http://addons.eksmo.ru/it/Unity.zip. В нём находятся модели, текстуры, шрифты, звуки и примеры. Доступ из текущей среды блокируется CONNECT403. Официальный репозиторий автора mikegeig/UnityGameDev_24Hours найден, но пуст. Другие читательские работы не выдаются за файлы автора.

Нужны оригинальный архив или его папки по часам, особенно Torus/Robot Kyle/Brick для часа3, Terrain/Environment/Characters для4/6/10/12, тайлсеты13, пакет14, спрайты15, StandardAssets/ParticleSystems16, RobotBoy17, Ethan/анимации18/20, клипы+звук19 и Sounds21. Точные имена и настройки — в ../audit/hours01-12.md и ../audit/hours13-24.md.

Инструмент ../tools/build_book_materials.py подготавливает две кирпичные сцены часа3 только после передачи настоящих PNG из архива; без файлов останавливается. Он не выполняет практикумы Torus/Kyle и здесь с оригиналами ещё не запускался.

Мобильный час22 требует телефона/USB/Unity Remote; час15 — реального плейтеста; час23 — настоящей сборки и запуска; час24 — разбора с реальными наблюдениями. Эти действия не подменяются выдуманными отметками.
